# 验证范围

自动测试用合成图像、原创几何与假串口，覆盖文档兼容、原位编辑、输入法、分栏/装饰线、照片旋转/透视、曲面、图片线稿、参考点映射、授权失效、队列和暂停/停止行为。

建立独立仓库时，本机 Windows / Python 3.12 完整运行 300 项测试通过（包含本机可选字体和照片检查）。远程干净环境的结果以 CI 为准。

Windows CI 在 Python 3.12、3.13 运行完整 unittest，另构建 wheel/sdist，在仓库外从 wheel 安装后测试入口与资源，再打包 Windows EXE 并执行 `--smoke`。`tools/check_repository.py` 检查受跟踪/待提交文件和分发包；Gitleaks 扫描提交内容，PR 还执行 dependency review。Actions 结果是当前远程验证依据。

依赖个人本机厂商字体和实拍照片的测试是可选集成检查，在干净 CI 中预期跳过。其余测试使用合成数据，不要求厂商软件或硬件。当前仓库不分发来自厂商的字形缓存或用户照片。

## 0.7 模块化与 Agent 接口验收（2026-10-25）

Windows / Python 3.12.7 完整测试 **397 项全部通过，未跳过**。保留原有设备协议、排版及九款字体回归，新增设备能力/配置验证、无 Z 轴舵机模拟器、GUI 与 API 的共享编辑和撤销、文档版本冲突、工作目录边界、HTTP/CLI/MCP，以及作业恢复与幂等检查。

作业测试覆盖先持久化后发送、重复请求只返回原作业、旧进程作业标为未知且不重放、存储失败锁定新动作、命令接受与完成观察分离、暂停/恢复及待执行动作的授权失效。实际 Grbl 的停止语义仍为保持并锁定；不能把暂停、串口 ACK 或断开连接当作实体队列已清空。

桌面授权测试覆盖确认期间页面/设备变化、旧范围授权回执、授权撤销及过期。公开接口不接受客户端提供的预检通过标志或运动确认。手推位移仍无法读取；能力字段明确标记无此反馈。

wheel 安装后和双入口 Windows 包分别从独立工作目录运行验收：导入合成照片、结构化中英混排/下划线/双栏/保护区、PNG 与 SVG、保存重开、模拟作业与幂等启动，并使用官方 MCP SDK 2.3.0 建立真实 stdio 会话、读取文档及预览图片。SDK 客户端与服务均经过实际调用，未以伪造 MCP 请求替代。

本轮不连接真实串口或移动设备。颂博士历史参数保留；通用 Grbl 模型属于未验证配置，舵机适配仅在内存模拟器验收。增加真实机型仍需协议与现场验证；模拟完成证据不会标为实机完成。远程构建与安全检查以对应提交的 CI 为准。

同时将开发/字体构建依赖升级到 [Pillow 13.0.0](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)，移除阻止安装上游修复版本的旧上限。Pillow 不进入便携版；现有九款内置资源沿用已核对的构建产物，未因依赖升级重生成字体。

## 0.6 内置字体验收（2026-10-25）

Windows / Python 3.12.7 最终完整测试 **314 项全部通过，未跳过**。新增覆盖九款内置字体、中文/英文回退、比例字宽、补充平面字符、输入法、不可见字符、资源版本和许可入口；原有混排、分栏、下划线、保存重开与设备队列回归同时通过。

`tools/check_builtin_fonts.py` 逐条检查九库合计 **135,849 条字符映射**：可用 Unicode、有限笔迹坐标、空白与空源映射、数据库完整性、代理字体 cmap/advance 对应、资源 SHA256 和许可全文。九款混排页面的预检、SVG、项目保存重开及原生 UI 图像已离线验收。完整转换覆盖源 cmap，不能当作每个汉字都已人工校对。

wheel/sdist 的发布内容检查通过。独立环境从 wheel 安装后，在仓库外验证九款字库、图标、三个内置示例和程序入口；Windows EXE 在独立工作目录通过含九款字库的 `--smoke`。普通运行无字体下载和转换依赖。最终远程结果仍以对应提交的 CI 为准。

这一轮没有连接串口、移动机器或改动原软件；新内置字体尚未实机试写，不能把既有厂商字体的硬件结果算到这些字库上。

## 历史实机观察

2026-10-25，颂博士 2024 款在废纸上：

- 2 mm 抬落行程曾有方框缺墨；4 mm 行程后四边完整。
- 3000 / 4000 / 3000 mm/min 小方框约 0.782 秒，用户确认无拖痕。
- 使用原软件名义速度与 5 mm 行程的快写「永中」完成并确认完整、无字间多余连线；方向修正后约 1.328 秒，字朝纸上、永左中右。

以上耗时是作业阶段，不含现场定位。试验位置也有变化，不能单独认定缺墨的机械原因，或推算整页速度。高于固件上限的名义速度受固件限制。
