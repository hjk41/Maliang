# 使用指南

## 照片

量取纸页实际宽、高，导入照片；JPEG 会按 EXIF 转正。横向照片可以先转 90°，再对齐四角。四点可拖动、放大与微调，校正预览会同步显示。页面弯曲可沿本应水平的文字加参考线。拉平是二维近似，不能保证恢复书脊附近的真实比例。

在已有文字上画「禁落笔」保护区，在书夹等障碍上画「禁经过」保护区。导入照片不会自动识别内容。换照片、尺寸、四角或底图位置会使现场定位失效。

## 批注

单击页面文字进入原位编辑，拖选后改字号、字体和下划线；中文输入法提交后才写入项目。移动工具可拖动文字框，边缘把手改尺寸，圆形把手改方向。单栏 / 双栏 / 三栏共用富文本，按栏顺序流动；可开启真实栏间分割线。保护区绕排按每行剩余空间布局，放不下时提示或加高。

图画可导入位图或 SVG，转换为单笔线稿与排线。擦除工具修改保留的笔迹，不破坏源图。估算时长是基于路径的模型，尚未逐图实测。图画不自动绕开保护区，冲突需自行调整。

系统字体产生轮廓，仅供预览；文字实际发送需要自己有权使用的单线 `.gfont`。字库名称含「行书」并不保证更少抬笔，可比较路径数量。字号按统一字身范围换算，实物尺寸仍需试写核对。

## 书写

按向导连接设备、选择书本实体摆放、声明笔尖附近净空，并用页面方向点动或手动定位到可辨认特征，再点击照片对应点。实体倒置 180°时选择倒置预设，照片保持正常朝向。斜放需要三点标定。

用细步升降把笔尖调到刚碰纸，记下接触高度；向导设置抬落高度并抬笔。离纸与多压距离在高级功能调整。弹簧补偿不能替代当前位置和净空核对。先在可测试空白处点位置画 4 mm 方框，核对方向、尺度、位置和墨迹，再开始正式书写。

手推、换书、重新声明净空、断线、reset 都可能使当前标定失效。软件无法读到手推后的真实位移，点击「已经手推笔尖」后重新定位。保存项目不保存运动权限。

暂停请求 Hold 并等待确认；停止请求 Hold、清本地队列并锁定，设备队列需单独 reset。所有 ACK 到齐后仍要等新鲜 Idle。不要把继续 Hold 当成跨断电的可靠续写。

「更多 → 显示高级功能」可展开三点对准、独立 Z 采集、固定抬落行程、速度、净空、手动工作边界和会话授权。
