四款已有真实单线 SVG 路径，现已在 0.6 内置。大小写、数字、标点和易混字符已做离线样张检查；没有增加跨字母连线，尚未实机测速。用户认可样张外观，不代表实机书写验收通过。

后续选型同时检查英文、中文、数字和标点的混排，允许中文与英文选用不同字库。

早期曾对五款中文候选做第一轮单线示例转换：每款 23 个不同的样本字，包含两行同文样张和“慢漫惕惜已己未末”易混字检查。下表为当时示例的历史计数；0.6 全量资源采用加速实现，当前覆盖和计数以资源目录与完整检查结果为准。尚未进行新内置字体的实机试写。

| 字体 | 两行共 16 字的落笔路径数 |
|---|---:|
| 猫啃硬笔楷书 | 151 |
| 霞鹜文楷 GB | 155 |
| 小赖 | 131 |
| 悠哉 | 140 |
| 演示夏行楷（已排除） | 166 |

以上是当前自动转换的路径数，不是传统书法笔画数或实测速度。小赖的路径数最少；夏行楷粗细变化较大，骨架短支较多，用户已决定放弃。自动转换尚未恢复传统笔顺。

演示夏行楷缺少基本 ASCII 中的 `*`，不能作为唯一符号字库。

## 新的行书线索：待用户选择

2026-10-25 继续寻找原生单线行书，发现本机原软件已安装的字库包含以下真实笔迹路径。只读检查与预览均在本机完成；未核实开源授权，未将字体文件随马良公开分发，也未自动加入已认可的备选清单。

| 本地字库 | 同样 16 字的落笔路径数 | 检查结果 |
|---|---:|---|
| 乐行书 | 101 | 原始单线轨迹，23 个样本字均有字形 |

“乐行书2”在本次 23 个样本字上的路径与“乐行书”完全相同，未重复展示；不能据此推定两套完整字库一致。预览保留原始路径，仅按共同参考字缩放字身并设置统一字距，不解读或改写原软件的字体元数据。公开仓库 [CNCDraw](https://github.com/jiangmuran/CNCDraw) 也列有同名字库，但公开可下载不能作为字体授权证明。

另核验 [龙藏 Long Cang](https://github.com/m4rc1e/longcang) 和 [流江毛草 Liu Jian Mao Cao](https://github.com/googlefonts/liujianmaocao) 的 OFL 1.1，完成各 23 个样本字的本地中心线转换。同样 16 字分别为 163、110 条转换路径。两者原文件为轮廓 TTF，不属于现成的原生单线字库，字形和短支仍待筛选；尚未由用户认可为备选。

[拟草体 Computer Grass](https://github.com/LingDong-/computer-grass) 是另一条算法线索：以 MakeMeAHanzi 骨架模拟行草，字体数据 APL、程序 MIT。其正式发布物为轮廓 TTF，预编译版本以繁体为主，保留楷书骨架与笔顺的局限；不能作为成熟的简体单线行书成品推荐。

本轮未找到新的、成熟且许可明确的开源中文原生单线行书成品。以上均未进行本轮实机试写，路径数不能直接等同于写字耗时。
