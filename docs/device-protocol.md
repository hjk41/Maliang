# 设备协议与标定约束

已测试设备：颂博士 2024 款，控制器自报 BtWriter，使用 CH340 USB 串口及 Grbl 风格文本协议。通常为 115200 / 8N1，端口通过现场枚举选择。马良使用现有系统串口驱动。

## 连接、队列与完成

打开前设置 DTR/RTS=false。连接只查询状态，不自动 reset、回零、解锁、修改设置或设置工作零点。使用毫米坐标，`WPos = MPos - WCO`。标定与点动要求有效 WCO、两秒内的新鲜 Idle、空命令和状态队列。

`ok` 只表示处理或入队，不表示停稳。实机的 `G4 P0` 可在运动完成前返回 ACK；作业必须等最终新查询对应的 Idle。最终轮询约每秒四次；持续 Run 不会无限刷新总运动期限，暂停计入期限。

暂停发送 `!`，等待 Hold:0 才可继续；Hold:1 仍在减速。停止会清本地队列、请求 Hold 并锁定；设备队列需要独立 reset 才能清除，之后重新定位。断线、错误、ALARM、意外启动横幅和超时均不自动重放。

## 轴向与定位

仿射元组 `(a,b,c,d,tx,ty)` 的含义：`machine_x=a*x+c*y+tx`，`machine_y=b*x+d*y+ty`。

| 实体摆放 | 页面向右 | 页面向下 | 单点预设线性部分 |
|---|---|---|---|
| 已测正向 | Y+ | X− | `(0,1,-1,0)` |
| 相对正向倒置 180° | Y− | X+ | `(0,-1,1,0)` |

正向由用户观察废纸文字确认，倒置由两轴反转推导并通过离线测试。预设比例为设备毫米 1:1，尚无完整尺量误差数据；斜放或比例误差请用三个不共线点拟合。照片保持阅读方向，实体摆放交给映射处理。单点只能修正平移。

手推笔头没有编码器反馈，设备坐标可能不变。必须主动使旧标定失效、重新声明净空、重新对准和确认笔高度。不能用多次手推后的同一内部坐标采集三点。

## Z 与速度

已测本机 Z+降笔、Z−抬笔。原型默认固定行程 4 mm；新版向导记录接触点后，默认离纸 2 mm、再压 3 mm，依赖弹簧笔夹及现场核对，尚待新版实机验证。Z 高度属于本次会话，不能从保存项目恢复。

软件作业默认书写 / 空移 / Z 为 3000 / 4000 / 3000 mm/min。原软件曾保存 8000 / 8000 / 10000，而本次设备固件上限为 XY 4000、Z 5000；没有修改固件。精细点动独立限制为 XY 每步 ≤1 mm、≤300 mm/min；Z 每步 ≤0.25 mm、≤30 mm/min。所有动作还受本次净空和作业边界限制。

控制器曾报告 `Pn:XY`，即使用户观察笔在行程中间；其含义未确定，不能据此自动回零。
